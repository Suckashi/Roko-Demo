# Roko 介紹影片：三個故事線

素材全部來自真實產品：`web/src/roko/roko-spritesheet.png` 的吉祥物動畫（idle、waiting、running、review、jumping、waving），以及用假後端驅動真實前端截取的聊天畫面。
貫穿全片的一筆真實資料：「聚餐總共 3,860 元，6 個人，加一成服務費，每人要付多少？」→ `calculator` 算出每人 707.67 元。

## A.「Roko 動手做」（推薦）

**手法**：角色親自做事 × 物件接力鏡頭。
Roko 這隻石頭小機器人把你的問題當成一件差事：先把訊息泡泡「搬」進待辦清單，再一路跑去按 `calculator`，最後捧著答案回來，跳一下慶祝。觀眾不用懂 Agent 是什麼，看 Roko 跑一趟就明白它會規劃、會用工具、會把每一步攤開給你看。

- **前 2 秒**：第 0 格是放大 1.8 倍的真實輸入框，裡面已經是那句分帳問題，游標按下送出；訊息泡泡一飛出去，Roko 從畫面右邊探頭，眼睛跟著泡泡轉過去。
- **節奏**：鉤子（送出問題）→ 張力（一長串數字和「每人多少？」在 Roko 頭上打轉，狀態「思考中…」）→ 揭示（片名「Roko」）→ 證明（列待辦 → 跑去呼叫 calculator → 結果回來，三個動作各一鏡）→ 收穫（答案逐字串流出來，「每人 707.67 元」放大到全畫面，Roko 跳起來，狀態「完成！」）→ 一句話（「每一步，都看得見」）→ 片尾卡（Roko 揮手帶出名字和 `npm run dev`）。
- **風格**：底色取自 Roko 的砂岩（#E9DFD3，2% 細顆粒），文字墨色 #1C1A17，強調色只用 Roko 眼睛的琥珀色（#FFB23F），只出現在答案數字和片尾卡；字型 Noto Sans TC 粗體；產品 UI 用原本的白底卡片和虛線框。
- **聲音**：輕快的木質打擊樂 110 bpm；「思考中」那段只剩低音，答案出來那一拍音樂全開；送出、勾選待辦、按工具、答案落定各配一個音效。

## B.「把開關打開」

**手法**：產品功能本身當鉤子 × 先給結果、再一鏡到底拉遠。
開場直接是答案「每人 707.67 元」，乾淨，但你不知道它怎麼來的。游標按下右上角真實的「顯示 Agent 步驟」開關，答案上方一層層展開待辦清單、工具呼叫和工具結果，鏡頭一路往上拉，把整條推理鏈攤在眼前。

- **前 2 秒**：滿版的答案泡泡「每人 707.67 元」，一個大游標從右上方進場，停在開關上。
- **節奏**：鉤子（只有答案）→ 張力（一個問號：「這個數字，怎麼來的？」）→ 揭示（按下開關）→ 證明（鏡頭往上拉過：結果 → calculator 呼叫 → 待辦清單 → 原本的問題）→ 收穫（拉到全景，整段對話一次看完，Roko 在頂端狀態列跳一下）→ 一句話 → 片尾卡。
- **風格**：純產品 UI 世界，白底、黑色使用者泡泡，用鏡頭推拉代替剪接；琥珀色只給開關打開的那一下和片尾卡。
- **聲音**：極簡鋼琴加滴答節拍 90 bpm；開關「喀」一聲之後弦樂進來；每展開一層配一聲輕敲。

## C.「換腦，不換石頭」（大膽版）

**手法**：型別帶論點 × 匹配剪接。
Roko 永遠站在畫面正中央、姿勢不變，它身後的世界和右上角的模型名稱照著節拍一直換：OpenAI → OpenRouter → Groq → DeepSeek → vLLM → Ollama。每換一次，背景顏色、字型大小都跟著跳，只有 Roko 那雙琥珀色眼睛不變。主打「任何 OpenAI 相容 API 都能接」。

- **前 2 秒**：滿版大字「換一顆腦」，最後一個字「腦」縮小變成右上角的模型按鈕，Roko 從按鈕下方落地。
- **節奏**：鉤子 → 每半拍換一次模型和世界（6 次）→ 設定視窗「測試連線」打勾 →「不用重新啟動」→ 片尾卡。
- **風格**：大面積色塊搭配超大粗體字，每個世界一種底色；Roko 的砂岩質感是唯一不變的材質。
- **聲音**：128 bpm 電子節拍，每次換世界都卡在拍點上；最後一拍收住，接到片尾卡的落地音效。

---

**預設前提**：1920×1080、30 fps，長度 20–30 秒，只配音樂、不加旁白和字幕。這個環境沒有登入 HeyGen，所以沒辦法從它的曲庫挑配樂：免費做法是你提供一首自己的音樂（或我先輸出無聲版，之後再把音樂加進去）。
