# Workshop 對戰企劃：訓練家 × Clawd

你是訓練家，派出夥伴 Clawd，一路打倒每個 Step 擋路的寶可夢。每隻對手就是那一階「卡在」的問題；Clawd 的招式就是工作坊教的方法。

## 角色

- **訓練家**：你（工作坊講者），像素造型照你本人的特徵畫。
- **Clawd**：你的夥伴。造型取自 Claude Code 程式碼裡的 11×8 像素定義，再畫成寶可夢圖風（深色外框、明暗、眼睛反光）。Step 越高，Clawd 越多：1 → 5–10 → 約 100 → 1,000+ 隻（p.4 的數量）。
- **對手**：從 PokeAPI 1,025 隻寶可夢的圖鑑說明裡，挑出最貼近每個 Step 問題的一隻。

## 每一場怎麼打

### Step 1・VS 引夢貘人

- **牠的招式**：
  - 「催眠術」：訓練家的眼睛變成漩渦，黏在螢幕上（p.3 投票 Q1：「盯著它，怕它做錯」）
  - 「念力」：Clawd 陷入混亂，做歪了（p.3 Q3：「需求講不清楚，它會做歪」）
- **Clawd 的招式**，四格招式選單：
  - 「連環追問」：grill-with-docs 把需求問到可驗收，解除混亂（p.9）
  - 「Worktree 分身」：一個 Session 一個 Worktree，分身不打架（p.10；對應 Q3「同時改同一份 code，會打架」）
  - 「自我驗證」：Agent 自己跑 TDD 與 Test、Build、Lint、E2E，人只看證據（p.11；對應 Q3「做太快，來不及 Review」）
  - 「乾等」：笑點招式，效果不太好…（p.3 Q1：「等它跑完，順便泡杯咖啡」）
- **結果**：引夢貘人倒下，Step 2 解鎖。這三招也就是 p.18 收尾給的三個做法。

### Step 2・VS 卡比獸

- 5 隻 Clawd 交出的 PR 堆在路上，卡比獸躺在 PR 堆上睡著，擋住去路。
- 訓練家先選「全部逐行看」，想用手推開卡比獸：推不動，效果不太好，訓練家的血條反而掉一截。
- 改用「三層煞車」（p.22）：自動化檢查 → 自動化 Review（對照 coding-standards.md，能修的直接 commit，p.23）→ 人工只細看單向門（p.24）。卡比獸醒來讓路，Step 3 解鎖。

### Step 3・VS 百變怪

- 百變怪變成一份「看起來完全正確」的 PR，甚至變成 Clawd 的樣子，但臉還是百變怪的臉。
- 對應 p.20「Step 3 的門檻是信任」。
- Clawd 使出「Verifier 實測」和「隔天抽查」（p.19）：拿放大鏡一看，識破變身。
- 但 p.20 列了五層還沒補齊的信任（公司的態度、工程師的把握、測試環境、Domain 知識、Agent 的環境），所以只打掉一半，字幕寫「戰鬥還在繼續」。

### Step 4・屬性：空

- 只露剪影，配上「我是誰？」的經典猜謎畫面；打法「？？？」，字幕「再往後」。

## 畫面上一直在變的兩件事

- **訓練家站得越來越遠**：Step 1 貼在 Clawd 旁邊；Step 2 站在後面指揮；Step 3 坐在遠處喝咖啡抽查；Step 4 在山頂插旗定方向。對應 p.4「Step 越高，人盯得越少」。
- **Clawd 越來越多**：1 → 5–10 → 約 100 → 1,000+ 隻。

## 畫風

- 仿寶可夢第 4、5 代的對戰畫面：天空和草地背景、橢圓草地台座、米白色血條框（橘色 HP 標籤、綠色血條）、底部訊息框、四格招式選單（PP 和屬性）。
- 畫面以 320×180 的原生解析度設計，放大 6 倍輸出 1920×1080，像素才會銳利。
- 對手用 PokeAPI 的黑／白版動態圖（引夢貘人會甩鐘擺），拆成逐格圖後跟著時間軸播放。
- 字型：Fusion Pixel 12px（繁體中文像素字型，OFL-1.1）。

## 結構選項

**A. 一支「攻略預告」**：約 25–30 秒，在 p.4 播。地圖 → 每場對戰各剪一個高潮 → 回到「今天走到這裡」。

**B. 連續劇**：每集 10–15 秒，講到哪一頁播哪一集。

| 集數 | 搭配 | 內容 |
|---|---|---|
| 第 1 集「出發！」 | p.4 | 「去吧！Clawd！」四個對手輪流登場，只講「卡在」；結尾「今天的目標：打倒引夢貘人」 |
| 第 2 集「VS 引夢貘人」 | p.18 收尾 | 牠的招式對上開場投票的擔心，Clawd 三招反擊，Step 2 解鎖 |
| 第 3 集「VS 卡比獸」 | 附錄 p.22–24 | 「全部逐行看」推不動，三層煞車讓牠讓路 |
| 第 4 集「VS 百變怪」 | p.19–20 | 識破變身，但信任還沒補齊，未完待續 |
| 番外「Clawd 的裝備」 | p.6 | 就是 V2：Clawd 本身是 Model，一件件穿上 Harness 裝備 |

角色和對戰介面只做一次，每集重複使用。
