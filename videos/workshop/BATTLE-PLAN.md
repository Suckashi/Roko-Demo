# Workshop 對戰企劃：訓練家 × Clawd

你是訓練家，派出夥伴 Clawd，一路打倒每個 Step 擋路的怪獸。每隻怪獸就是那一階「卡在」的問題；Clawd 的招式就是工作坊教的方法。

## 角色

- **訓練家**：你（工作坊講者），像素造型照你本人的特徵畫，不用小智的帽子和衣服。
- **Clawd**：你的夥伴。Step 越高，Clawd 越多：1 → 5–10 → 約 100 → 1,000+ 隻（p.4 的數量）。
- **對手**：每個 Step 一隻原創怪獸。

## 每個 Step 的問題

### Step 1・盯盯獸 Lv.1

- **p.4 原文**：一個人盯著一個 Agent；你在做「與 Agent 配對工作」；卡在「人的注意力」。
- **觀眾自己的話**（p.3 投票 Q1）：「盯著它，怕它做錯」「等它跑完，順便泡杯咖啡」。
- **Boris Cherny 的說法**：Agent 不會自己驗證，人只好每一行都讀。
- **特性「目不轉睛」**：訓練家的眼睛離不開螢幕。
- **盯盯獸的三招**，就是 p.3 投票 Q3 的三個擔心：
  - 「做歪光線」：需求講不清楚，它會做歪
  - 「撞車衝擊」：同時改同一份 code，會打架
  - 「爆量轟炸」：做太快，來不及 Review
- **Clawd 的三招反擊**，就是 p.18 收尾給的三個做法：
  - 「連環追問」：grill-with-docs 把需求問到可驗收（p.9）
  - 「Worktree 分身」：一個 Session 一個 Worktree（p.10）
  - 「自我驗證」：Agent 自己跑 TDD 與 Test、Build、Lint、E2E，人只看證據（p.11）
- **結果**：盯盯獸倒下，Step 2 解鎖。但「爆量轟炸」只擋下一部分，剩下的 PR 堆成下一隻怪獸。

### Step 2・PR 山怪 Lv.2

- **p.4 原文**：一個人協調多個 Agent；你在做「分派任務、審閱成果」；卡在「Review 多份成果」。
- **附錄 p.22**：Agent 越多，PR 越多。Cherny 的說法：十個 Agent 做完的速度，比一個人看懂的速度快。
- **特性「越堆越高」**：每多一隻 Clawd，牠就長高一截。
- **招式「假綠燈」**：CI 全綠，測試卻沒驗到行為（p.23 的三種騙法：套套邏輯、對結構過敏、不可能失敗）。
- **笑點**：訓練家先選「全部逐行看」，結果效果不太好，訓練家自己的血條反而掉一截。
- **Clawd 的反擊「三層煞車」**（p.22）：
  1. 自動化檢查：Test、Build、Lint、E2E
  2. 自動化 Review：對照 coding-standards.md，能修的直接 commit（p.24）
  3. 人工 Review：只細看單向門，雙向門看摘要就好（p.25）
- **結果**：山怪縮成一顆小石頭，Step 3 解鎖。

### Step 3・疑心霧 Lv.3

- **p.4 原文**：Agent 自主推進，人處理例外；你在做「監督工作流程與例外」；卡在「驗證可信度與決策速度」。
- **p.20**：Step 3 的門檻是信任。
- **特性「疑神疑鬼」**：每次合併前都冒出「真的可以嗎？」
- **血條分五格**，就是 p.20 的五層：公司的態度、工程師的把握、測試環境、Domain 知識、Agent 的環境。
- **Clawd 的反擊**（p.19、p.20）：Verifier 實測、通過驗證才合併、隔天抽查 commit 歷史、/retro 改環境、低風險變更先試行。
- **結果**：一格一格打掉，打到一半字幕寫「戰鬥還在繼續」，呼應 p.20「信任是一項一項補出來的」。

### Step 4・邊界魔王 Lv.4

- **p.4 原文**：人用意圖決定方向；你在做「設定目標與操作邊界」；卡在「辨識可自動化工作與設定邊界」。
- **投影片沒有給打法**：只露剪影，打法「？？？」，字幕「再往後」。

## 畫面上一直在變的兩件事

- **訓練家站得越來越遠**：Step 1 貼在 Clawd 旁邊；Step 2 站在後面指揮；Step 3 坐在遠處喝咖啡抽查；Step 4 在山頂插旗定方向。對應 p.4「Step 越高，人盯得越少」。
- **Clawd 越來越多**：1 → 5–10 → 約 100 → 1,000+。Step 4 時，1,024 隻小 Clawd 排成一隻大 Clawd。

## 結構選項

**A. 一支「攻略預告」**：約 25–30 秒，在 p.4 播。地圖 → 每場對戰各剪一個高潮 → 回到「今天走到這裡」。

**B. 連續劇**：每集 10–15 秒，講到哪一頁播哪一集。

| 集數 | 搭配 | 內容 |
|---|---|---|
| 第 1 集「出發！」 | p.4 | 「去吧！Clawd！」地圖上四個對手輪流登場，只講「卡在」；結尾「今天的目標：打倒盯盯獸」 |
| 第 2 集「VS 盯盯獸」 | p.18 收尾 | 盯盯獸的三招對上開場投票的三個擔心，Clawd 三招反擊，Step 2 解鎖 |
| 第 3 集「VS PR 山怪」 | 附錄 p.22–25 | 「全部逐行看」的笑點，接著三層煞車 |
| 第 4 集「VS 疑心霧」 | p.19–20 | 五格血條打掉兩格，未完待續 |
| 番外「Clawd 的裝備」 | p.6 | 就是 V2：Clawd 本身是 Model，一件件穿上 Harness 裝備 |

角色和對戰介面只做一次，每集重複使用，所以多集不會多花太多工。
