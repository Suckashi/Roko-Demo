# V1、V2 故事線：Clawd 主演版（討論用）

上一版（深色圖表、60–75 秒）留在 git 歷史；這一版改成：**可愛、Clawd 當主角、每支 20 秒左右**。

## 兩支共用的設定

- **主角 Clawd**：Claude Code 的吉祥物。像素造型直接取自 Claude Code 程式碼裡歡迎畫面的定義（11×8 格），身體色 `rgb(215,119,87)`（#D77757）、黑色眼睛，都是程式碼裡的原值。眨眼、走路、揮手、跳等動作是用同一組像素延伸的，不是官方動畫。
- **整個世界都是像素風**：人、桌子、筆電、PR、測試燈號都用同一個像素格畫，Clawd 才不會像貼上去的。底色沿用投影片的深海軍藍 #091522（影片在投影片中間播，接得上），畫面一律鋪滿場景，不讓小東西漂在深色背景中間。
- **顏色分工**：Clawd 橘 #D77757；人穿投影片的青色 #59D4ED；琥珀 #FFC96B 只給「卡點」和最後一句；測試失敗紅、通過綠各一個純色。
- **字型**：Fusion Pixel 12px（繁體中文像素字型，OFL-1.1 授權，可以從 npm 取得），字幕跟角色同一種像素風。
- **規格**：1920×1080、30 fps，每支約 20 秒，不加旁白，字幕一行最多 10 個字。
- **聲音**：先做無聲版，你在台上邊講邊播。之後想加，可以補 8-bit 風格的音效。

## V1「Agent 攻略地圖」（搭配 p.4，約 25 秒）

每個 Step 都有一隻擋路的怪獸，怪獸就是那一階的「卡在」；用工作坊教的方法打倒牠，才能往下一關。玩法是寶可夢式對戰（血條、招式選單、「效果絕佳！」），怪獸全部原創。

| 時間 | 畫面 | 對話框／字幕 |
|---|---|---|
| 0–2 秒 | 攻略地圖：工程師帶著 Clawd 走上第一關，畫面一閃切進對戰 | |
| 2–8 秒 | **盯盯獸 Lv.1** 出現，牠一瞪，工程師的眼睛就黏在螢幕上。選「分身術」：Clawd 分裂成 5 隻，各自跳進自己的資料夾（Worktree）；再選「自我驗證」：每隻頭上亮起綠色 ✓。盯盯獸轉圈圈倒下 | 盯盯獸出現了！／卡在：人的注意力／效果絕佳！／Step 2 解鎖 |
| 8–15 秒 | **PR 山怪 Lv.2** 出現，5 隻 Clawd 交出的 PR 讓牠越長越高。先選「全部逐行看」：沒什麼效果，工程師的 HP 反而掉一截；改用三層煞車：自動化檢查、AI Review、只看單向門，三招各打掉一截，山怪縮成一顆小石頭 | PR 山怪越長越高了！／效果不太好…／Step 3 解鎖 |
| 15–20 秒 | **疑心霧 Lv.3** 出現，整個畫面起霧：「真的能讓 Agent 自己合併嗎？」選「Verifier 實測」和「隔天抽查」，霧散了一半，血條剩一半 | 戰鬥還在繼續…收尾時再看 |
| 20–23 秒 | 地圖盡頭：**邊界魔王 Lv.4** 的剪影，打法是「？？？」 | 再往後 |
| 23–27 秒 | 鏡頭拉回地圖，Step 2 插上旗子，最後一句放大 | 今天走到這裡／能放手，靠的是驗證與 Guardrails |

- **怪獸與原文**：每隻怪獸的「卡在」沿用 p.4 原文，畫面上可能縮短，例如「驗證可信度與決策速度」寫成「驗證可信度」。
- **招式出處**：分身術是 p.5、p.10 的多 Session 加 Worktree；自我驗證是 p.11 的 Agent 自己跑 Test、Build、Lint、E2E；三層煞車是附錄 p.22；Verifier 和隔天抽查是 p.19。Step 4 投影片沒有給打法，所以寫「？？？」。
- **節奏剛好對上工作坊**：打倒盯盯獸是今天的 Demo，PR 山怪是附錄，疑心霧是收尾那段。
- **要更短的話**：Step 3 和 Step 4 合成一段，約 20 秒。
- **不用寶可夢角色**：寶可夢的角色版權屬於任天堂、Game Freak 和 The Pokémon Company。疑心霧、邊界魔王也刻意避開了小精靈（Pac-Man）的鬼和太空侵略者（Space Invaders）的外星人造型。

## V2「Clawd 接到一張單」（搭配 p.6，約 23 秒）

如果 V1 走遊戲風，V2 可以順著改成 RPG 的「裝備欄」：Clawd 本身是 Model，一件件穿上 Harness 的裝備（背包 Runtime、機械手臂 Tools、測試燈 Sensors、護欄 Guardrails、技能書 Skills、地圖卷軸 Repo 知識）。

用 Demo 的 Task A（TSMC Week 週別換算工具）當這張單，p.6 圖上的九個角色都會出現。

| 時間 | 畫面 | 字幕 |
|---|---|---|
| 0–2.5 秒 | 人把一張工單丟給 Clawd：「週別換算工具：W641 ↔ 10/4–10/10」。Clawd 頭上冒出思考泡泡，裡面是程式碼 | 這是 Model：負責推理 |
| 2.5–5 秒 | Clawd 想去拿桌子另一頭的 `week.ts`，但手只有一格長，伸不到；它努力伸、冒汗 | 只有 Model，只會想、動不了手 |
| 5–8 秒 | 裝備一件件扣上 Clawd：背包（Agent Runtime）、一隻很長的機械手臂（Tools）。它終於拿到檔案，開始改 | Harness：幫它執行工具、控制循環 |
| 8–10.5 秒 | 一本「Skills」和一卷「GLOSSARY.md」攤開，文字流進 Clawd 頭裡 | Skills 與 Repo 知識：先告訴它怎麼做 |
| 10.5–15 秒 | 頭上的測試燈號亮起：「跨年週」紅燈。Clawd 舉牌問人「跨年週算哪一年？」，人回答；Clawd 修改，燈號轉綠 | Sensors：改完自己驗證，不確定就問人 |
| 15–17.5 秒 | 機械手臂伸向 `main` 想直接推上去，「咚」一聲撞上圍欄彈回來 | Guardrails：Branch 保護，碰不到就不會出事 |
| 17.5–19.5 秒 | Clawd 改走正路，開一份 PR 交給人 | |
| 19.5–23 秒 | 鏡頭拉遠：Clawd 本體標上「Model」，整套裝備標上「Harness」 | Agent = Model + Harness |

「跨年週算哪一年？」是示意的提問，呼應 p.14 的驗收條件「週別規則、跨年週與錯誤輸入可測試」，影片不會寫出任何實際的週別規則。
