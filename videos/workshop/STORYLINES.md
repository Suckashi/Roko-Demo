# V1、V2 故事線（討論用）

## 兩支共用的設定

- **風格**：沿用投影片自己的配色，播放時才接得上。底色 #091522（投影片的深海軍藍），文字 #EEF5FC，主色青 #59D4ED，強調色琥珀 #FFC96B 只給「卡點」和每支的最後一句，錯誤用珊瑚紅 #FF8D77。主體一律放大到畫面高度 40% 以上，不做「小方塊漂在深色背景中間」。
- **字型**：Noto Sans TC 粗體（下載字型檔放進專案），英文和數字用 Inter；畫面上的字至少 28 px。
- **規格**：1920×1080、30 fps，不加旁白，畫面上每一行最多 10 個字。
- **聲音**：你在台上會邊講邊播，建議先做**無聲版**；之後想加配樂，給我一首音樂就能加。
- **事實**：Agent 數量沿用投影片寫的「約 1、5–10、100、1,000+」，和投影片一致；Step 0 和每一階卡點的細節來自二手整理（見 PLAN.md 參考資料）。

## V1：五個台階（搭配 p.4）

### A.「瓶頸跟著你走」（推薦）
**手法**：機器就是解說 × 一路往外拉遠。
工作像沙子一樣從一個窄口流過，那個窄口就是「卡點」。每拉遠一次，Agent 從 1 個變 5–10 個、100 個、1,000+ 個，窄口也搬到新的位置：人的眼睛 → 一疊等 Review 的 PR → 一個信任量表 → 一道邊界圍欄。
- **前 2 秒**：一個人盯著一個終端機，Agent 每打一行字，人的視線就跟著動一下；窄口就在視線上。
- **節奏**：Step 0（一道鎖住的審批閘門，0 個 Agent）→ Step 1 → 拉遠 → Step 2 → 拉遠 → Step 3 → 拉遠 → Step 4 → 鏡頭推回 Step 2，標上「今天走到這裡」→ 最後一句「能放手，靠的是驗證」。
- **長度**：45–60 秒

### B.「同一個人的一週」
**手法**：某人一天裡的一個時刻 × 匹配剪接。
同一個工程師、同一張桌子，從週一到週五：週一盯著一個 Agent；週三開了 8 個分頁，桌上的 PR 越疊越高；週五下班走人，Agent 還在跑，隔天早上只抽查幾個。桌子的位置不變，桌上的東西一直在變。
- **前 2 秒**：週一 09:00，一個人臉貼著螢幕。
- **長度**：約 60 秒

### C.「一個數字長大」（大膽版）
**手法**：大字帶論點 × 照節拍硬切。
滿版巨大數字 0 → 1 → 10 → 100 → 1,000+，每切一次，那一階的卡點用一個詞重重砸下來（審批、注意力、Review、信任、邊界）。
- **長度**：約 30 秒；適合當開場的節奏短片。

## V2：Agent = Model + Harness（搭配 p.6）

### A.「一張單走一圈」（推薦）
**手法**：一個真實例子走完全程 × 一張會長大的圖。
用 Demo 的 Task A（TSMC Week 工具：W641 ↔ 10/4–10/10）當主角。一開始畫面上只有 Human 和 Model，Model 只會「說」怎麼做，什麼都沒改；接著 Runtime 和 Tools 一塊塊長出來，它開始真的改程式；Sensors 跑測試，跨年週那一題亮紅燈，退回去再修一輪，變綠；遇到「週別從哪天開始算」這種規則，回頭問 Human。Skills、Repo Knowledge 從上方注入（Guides），Guardrails 擋住不該碰的地方。圖最後長成跟 p.6 一模一樣，觀眾一回到投影片就認得。
- **前 2 秒**：工單「W641 是哪幾天？」丟給 Model，Model 回一段文字，但程式碼一行都沒變。
- **最後一句**：「Model 負責想，Harness 負責做和檢查」
- **長度**：60–75 秒

### B.「拿掉一塊會怎樣」
**手法**：反過來證明 × 同一張圖重建三次。
完整的 Harness 正常運作；然後一次拿掉一塊：拿掉 Sensors，Bug 安靜地上線；拿掉 Guides，同一個錯連犯三次；拿掉 Guardrails，它動到了正式環境。每拿掉一塊就是一個小失敗，帶出研究到的重點：Guides 和 Sensors 兩個都要。
- **長度**：約 60 秒

### C.「把機器剖開」（大膽版）
**手法**：機器就是解說 × 剖面圖。
把 Agent 畫成一台機器：Model 是引擎，Harness 是底盤、方向盤和儀表板，Sensors 是儀表，Guardrails 是護欄。鏡頭鑽進每個零件。比喻最生動，但離真實的程式碼最遠。
- **長度**：約 60 秒
